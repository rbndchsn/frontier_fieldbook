# RDR2 — Xbox controller quick reference

Default Xbox-style controls in Story Mode; context, settings and Highball input mapping may differ. Follow on-screen prompts where they conflict.

| Control | Common action |
|---|---|
| Left stick | Move / steer horse |
| Right stick | Look around / aim |
| A | Run or increase horse pace (tap/hold as prompted) |
| B | Melee / cancel, context dependent |
| X | Jump / vault; contextual interaction |
| Y | Mount / dismount; contextual interaction |
| LT | Aim weapon or focus on person/animal |
| RT | Fire when aiming |
| LB | Weapon wheel (hold) |
| RB | Take cover / slow horse, context dependent |
| D-pad Up | Whistle for horse |
| D-pad Down | Display information / radar options (context dependent) |
| View button | Change camera perspective |
| Menu button | Pause menu |
| Both sticks pressed | Eagle Eye when not aiming; contextual abilities may vary |

## First session
Practice walking, looking, greeting, mounting, stopping, turning, and camera changes before chasing objectives. Use the game's controller layout under Settings > Controls as the authoritative reference. Avoid pressing RT while trying to greet someone; focus with LT and follow the displayed social options.

## Connection
Pair Xbox controller in macOS Bluetooth settings (hold controller pairing button until light flashes). Test inside Highball/Steam. If inputs fail, check Steam controller settings and try the included USB data cable where supported. TV HDMI carries picture and sound; controller remains connected to Mac.
